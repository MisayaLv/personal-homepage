## 运行方法

无需安装前端依赖，直接打开 `index.html`。也可在项目根目录执行：

```sh
python -m http.server 8000 --bind 127.0.0.1
```

浏览器打开 <http://127.0.0.1:8000/>，结束时按 Ctrl+C。所有页面资源使用相对路径，适合部署在 GitHub Pages 的仓库子路径下。

## 内容与功能

首页、关于我、技能、三个项目和联系方式组成单页；导航使用原生锚点。桌面端项目三列，700px 及以下单列，技能标签自动换行。手机菜单支持 Escape 与跨断点重置，关闭 JS 仍可使用导航。

项目介绍保留：生成式推荐模型复现与评估、Semantic ID 表示方式对比实验、推荐算法与深度学习实践。姓名与邮箱按本人提供填写，专业和入学年份未提供，因此不展示。邮箱链接只打开邮件应用，不自动发送邮件。
